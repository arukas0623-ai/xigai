# 析概 · 知识图书馆 📚

**析概** 是一座「会思考的图书馆」：它以图书馆书架的形态呈现不同领域与专业的概念名词，点击任意一本书即可打开 AI 综合整理的**概念解析**——解析数据来自**全网搜索 + AI 分析**。内置**模糊搜索**（支持中文、别名、标签、拼音）、**金色知识图标**与**多主题换肤**，并附带收藏、阅读历史、每日藏书、随机开书等拓展功能。

## ✨ 功能总览

| 需求 | 实现 |
|---|---|
| ① 图书馆式 UI | 木质书架墙、烫金书脊、领域铭牌、氛围光尘；点击书籍打开概念解析卡片 |
| ① 解析来源 | 种子语料 12 个领域 × 120 个概念：每个概念均经真实联网搜索（web_search）+ AI 综合分析撰写，含定义/背景/核心要点/应用/误解/相关概念/参考来源 |
| ① 动态解析 | 书库未收录的概念可一键 AI 深度解析（本地引擎联网研究，结果缓存 7 天），另有百度百科速览实时查询 |
| ② 模糊搜索 | 中文子串 + 拼音全拼/首字母（如 tlj → 图灵机）+ 别名/标签匹配，高亮显示，键盘导航 |
| ③ 金色图标 | 金色徽章 Logo（书本+星芒，SVG），烫金主题贯穿全站 |
| ④ 主题换肤 | 6 套主题（鎏金学院/深蓝夜读/古典羊皮/墨绿学者/晨光极简/蔷薇暖阳），可调字号/行距/书架视图 |
| ⑤ 分步高效完成 | 全流程拆解为 12 个步骤并行推进（见下方「构建过程」） |
| ⑥ 拓展延伸 | 收藏、阅读历史、每日藏书、随机开书、阅读进度条、相关概念跳转、链接直达（?c=id）、打印/复制、统计、快捷键等 |

## 🚀 快速开始

    cd D:\析概
    node server.js          # 默认端口 8765
    浏览器打开 http://127.0.0.1:8765

> 也可指定端口：node server.js 8899。AI 深度解析功能依赖本服务；静态浏览可直接打开 index.html（数据已内嵌，但联网类功能不可用）。

## 📖 数据与内容

- 120 个概念覆盖：计算机科学、人工智能、数学、物理学、天文学、生物学、经济学、心理学、哲学、语言与思维、文学艺术、历史文明。
- 每条概念含 16 个字段：id/name/aliases/field/tags/difficulty/summary/definition/background/core/applications/misconceptions/related/references/sources/searchedAt。
- 所有内容均由子代理并行联网搜索（web_search）→ AI 综合分析 → 自动校验生成，来源覆盖权威百科、高校课程、学术机构等（详见各数据文件内 sources）。

## 🧠 AI 深度解析（动态）

未收录的概念：在搜索框输入后回车，或在详情页点 ✨ AI 深度解析。服务端将调用本地 DSH headless 引擎（dsh --profile headless）联网研究并返回结构化解析，结果缓存 7 天（.cache/ai/）。消耗少量模型额度，弹窗确认后执行。

## 🛠 扩展新概念/新领域

1. 在 data/ 下新建 xxx.js，格式：window.XIGAI = window.XIGAI || {}; window.XIGAI["领域名"] = [ {…16字段…} ];
2. 在 data/manifest.js 的数组中加入 "xxx.js"。
3. 刷新页面即可上架（领域顺序可在 assets/js/core.js 的 DOMAIN_ORDER 调整）。

## 🌐 公网访问

本地服务默认跑在 `http://127.0.0.1:8765`。需要公网网址时（已内置支持）：

```
D:\析概\tools\cloudflared.exe tunnel --url http://127.0.0.1:8765
```

会输出一个 `https://xxx.trycloudflare.com` 公网地址（免费、即时、无需账号；重启后地址会变化）。

**.org 网址（xigai.js.org）**：已通过 GitHub Pages 部署 + js.org 子域申请流程配置（见部署说明），审核通过后生效。
